# Termux-Mobile-Tools 📱

مجموعة أدوات Termux خفيفة وسريعة للأندرويد - بالعربي

صنع بواسطة كالبسو

## 📦 الأدوات

| الاسم | الوصف | التشغيل |
|---|---|---|
| 13.sh | مباشر - يشتغل برقم WebSDR راديو 13 | `bash 13.sh` |
| kalbaso.py | أداة خفيفة - إدارة حزم ورفع سريع لجيثاب | `python kalbaso.py` |
| kalbaso_studio_v7.py | 🔥 استوديو V7 - تثبيت ذكي + حفظ توكن + رفع مباشر + توليد setup.sh - شغل بـ 2027 | `python kalbaso_studio_v7.py` أو `2027` |

## 🚀 التحميل والتشغيل

افتح Termux واكتب:

```bash
pkg update && pkg install python git -y
pip install requests
git clone https://github.com/f9539510-commits/Termux-Mobile-Tools.git
cd Termux-Mobile-Tools
python kalbaso_studio_v7.py
# أو شغل بالأمر السريع
